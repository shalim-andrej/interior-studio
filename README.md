Двухстраничный сайт студии дизайна интерьеров: главная (услуги, работы, процесс, заявка) и кейс квартиры (задача, решения, планировка, результат).

🌐 **[Открыть демо](https://interior-studio-kappa.vercel.app)** · 📄 **[Страница кейса](https://interior-studio-kappa.vercel.app/case.html)**

> Демонстрационный проект для портфолио. Студия, адрес, телефон, цены, сроки и проекты вымышлены.
> Изображения — визуализации, созданные нейросетью. Форма заявки в демо-режиме: данные никуда не отправляются.

## Страницы

| Файл | Что внутри |
|---|---|
| `index.html` | Герой с фото, цифры, 4 услуги с ценами, 3 работы, 4 шага процесса, материалы, форма заявки |
| `case.html` | Заголовок и факты, галерея, задача, 4 решения, планировка, результат, призыв к действию |

## Что внутри проекта

- Адаптивный дизайн: десктоп, планшет, телефон, бургер-меню
- Появление блоков при прокрутке, с учётом настройки системы «меньше движение» (`prefers-reduced-motion`)
- Демо-форма с проверкой полей и понятным сообщением без отправки
- Семантическая вёрстка: `header`, `nav`, `section`, `article`, `footer`

## Стиль

- Палитра: молочный `#f7f1e8`, терракота `#b4573a`, тёмный шоколад `#3a2820`, песочный `#dcc7ac`
- Заголовки: Manrope, акценты курсивом: Playfair Display
- Шрифты лежат локально в `assets/` и не зависят от интернета

## Запуск

Никакой сборки не требуется — это статический сайт:

- **VS Code:** установите расширение Live Server → правый клик на `index.html` → *Open with Live Server*
- **Python:** `python -m http.server 8000` в папке проекта → откройте `http://localhost:8000`
- Или просто откройте `index.html` двойным кликом в браузере

## Деплой

Сайт развёрнут на [Vercel](https://vercel.com): Framework Preset **Other**, Root Directory `./`, без сборки. Любой статический хостинг (GitHub Pages, Netlify) тоже подойдёт — достаточно загрузить файлы репозитория как есть.
